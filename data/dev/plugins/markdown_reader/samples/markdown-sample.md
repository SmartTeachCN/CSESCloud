# Markdown 阅读器示例

这是一份用于体验**分栏模式**（左侧预览 + 右侧源码）与**全预览模式**的示例文档。

> 提示：右上角可以随时切换「分栏 / 全预览 / 全源码」，`Ctrl + S` 保存。

## 常用语法

**粗体**、*斜体*、~~删除线~~、`行内代码`。

- 无序列表
  - 支持一层嵌套
- [x] 已完成的任务
- [ ] 待办的任务

1. 第一步
2. 第二步

### 代码块

```js
function hello(name) {
  return 'Hello, ' + name + '!';
}
console.log(hello('CSES Cloud'));
```

### 表格

| 模式 | 说明 | 快捷键 |
| --- | --- | --- |
| 分栏 | 左预览右源码 | Alt+1 |
| 全预览 | 只读阅读 | Alt+2 |
| 全源码 | 纯编辑 | Alt+3 |

### 引用与链接

> 引用块适合放结论或注意事项。

- 链接：[CSES Cloud](https://cses.cc)
- 图片：`![说明](图片地址)`（需要可访问的图片地址）
